# Polar Workspace (Claude Code Workspace)

Личный self-hosted Claude: **web-интерфейс чатов/проектов/файлов/терминала + настоящий официальный
Claude Code CLI по подписке**. Один Node-процесс, без сторонних API и без прокси-посредников.

Репозиторий: `evgenmay1978-del/claude-code-workspace` (private).

## Что внутри

| Слой | Файлы | Что делает |
|---|---|---|
| Интерфейс | `src/` (React + TS + Vite) | Чаты с потоковым ответом, проекты, дерево файлов и редактор, xterm-терминал, Source Control, поиск по истории, мобильная раскладка |
| Сервер | `server/index.mjs` | API + WebSocket + раздача собранного фронтенда; SQLite (`node:sqlite`), cookie-сессия владельца + CSRF, запуск CLI, git, файлы |
| Документы | `docs/` | План и исследования Manus (`docs/manus/`), авторизация подписки (`docs/AUTH.md`) |

Ключевой принцип: никаких Anthropic API-ключей и SDK. Каждый запрос уходит в **неизменённый
официальный `claude`**, установленный на вашем сервере; вход — штатный подписочный
(`claude setup-token`), токен остаётся в окружении/конфиге CLI, а не в браузере.

## Быстрый старт (сервер)

```bash
npm install
npm run build            # tsc + vite → dist/
npm start                # http://127.0.0.1:8787 — API + UI одним процессом
```

Первый вход: откройте адрес, создайте **единственного владельца** (логин + пароль ≥ 8 символов).
Пароль хранится как scrypt-хэш в `.data/polar.sqlite`.

### Авторизация Claude (подписка)

1. Установите официальный CLI: `npm i -g @anthropic-ai/claude-code`
2. Войдите подпиской: `claude setup-token` (ссылка от Anthropic, токен остаётся на сервере).
   То же можно сделать из интерфейса: **Настройки → Вход в Claude Code**.
3. Проверьте: `curl -s localhost:8787/api/health | ...` → `claude.installed: true`, `loginFilePresent: true`.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` / `HOST` | `8787` / `127.0.0.1` | адрес сервера (`HOST=0.0.0.0` — если ставите за Caddy/nginx) |
| `DATA_DIR` | `./.data` | SQLite, сессии |
| `WORKSPACES_DIR` | `./workspaces` | папки проектов (там работает CLI и git) |
| `CLAUDE_BIN` | `claude` | путь к официальному CLI |
| `CLAUDE_PERMISSION_MODE` | `acceptEdits` | режим разрешений CLI |

## Разработка

```bash
npm run dev     # vite на :3000, /api и /ws проксируются на :8787
npm start       # сервер (в отдельном терминале)
```

Проверка после изменений: `npm run test:api` — поднимает сервер на временных данных с фейковым CLI
и прогоняет 19 проверок: auth + CSRF, проекты и сессии, файлы и path-guard, git, SSE-поток Claude,
история и поиск, WebSocket-терминал, раздача собранного фронтенда.

## Модель безопасности

- единственный владелец, сессия в HttpOnly-cookie, все изменяющие запросы — с CSRF-заголовком;
- path-guard: файловые операции заперты в папке проекта, `.env`/`.credentials.json`/`*.pem`/`*.key` не читаются и не показываются;
- CLI запускается в каталоге проекта без root; секреты Claude браузеру не отдаются;
- наружу сервер смотрит только если вы сами поставите `HOST=0.0.0.0` и TLS-прокси перед ним.
