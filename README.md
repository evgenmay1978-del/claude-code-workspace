# Claude Code Workspace

Личная рабочая среда: интерфейс Claude + рабочее окружение Claude Code в браузере.

## Источник
Прототип интерфейса сделан в Manus и перенесён сюда (см. `docs/`). Исходники лежат в этом репозитории,
а не в облаке Manus.

## Состав
- `src/` — фронтенд (Vite + React + TS). **Сейчас UI ещё читает `src/data/mock.ts`** — это надо заменить на вызовы backend.
- `server/index.mjs` — реальный backend: официальный Claude Code CLI (подписка), файлы, терминал. Заглушек нет.
- `docs/AUTH.md` — как авторизовать подписку Claude (официально).

## Запуск
```
npm i
npm run build         # собрать фронтенд
node server/index.mjs # backend + API (по умолчанию 127.0.0.1:8787)
```
