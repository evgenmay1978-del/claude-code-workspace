# TODO — Claude Code Workspace

## 1. Главная и управление проектами
- [x] Главный экран показывает проекты со списком, быстрым поиском, статусами, недавней активностью и действием создания проекта; пользователь может открыть проект и переключиться между проектами.

## 2. AI-сессии и чат
- [x] Внутри проекта доступна навигация по AI-сессиям; пользователь может создать сессию, переименовать её, продолжить её и видеть визуальный статус текущей работы.
- [x] Диалог с Claude Code показывает историю сообщений и Markdown; содержит оформленные блоки кода, действие копирования и повторную отправку; демонстрационный ответ появляется постепенно, по словам, и не изображается реальным подключением к Claude Code.

## 3. Терминал и файлы
- [x] В рабочей области доступен интерактивный терминал с вкладками, имитацией выполнения команд, историей команд и понятными состояниями процесса.
- [x] Проводник проекта предоставляет дерево файлов, поиск, открытие файла и просмотр содержимого с подсветкой синтаксиса; исходный код можно отредактировать и локально сохранить в состоянии прототипа.
- [x] Markdown можно редактировать и просматривать с переключением между исходником и preview; preview поддерживает таблицы, списки, ссылки и блоки кода.

## 4. Source Control и контекст
- [x] Раздел Source Control/Git показывает изменённые файлы, позволяет открыть diff, менять staging-состояния, вводить commit message и выполнять демонстрационные Git-действия.
- [x] Управление контекстом проекта показывает выбранные файлы и инструкции, приблизительную оценку использования контекстного окна, позволяет добавлять материалы в контекст и исключать их из сессии.

## 5. Адаптивность, настройки и безопасность
- [x] Рабочая область адаптируется для компьютера, планшета и телефона, поддерживает переключение вкладок/панелей; на телефоне доступна упрощённая навигация вместо сжатой IDE-компоновки.
- [x] Экран настроек и безопасности объясняет self-hosted-модель, официальную авторизацию Claude Code и то, что учётные данные не передаются посреднику и не используются обходные прокси.
- [x] Все демонстрационные операции явно обозначены как прототип; кнопки и вкладки дают отзывчивые локальные состояния, а интерфейс не утверждает, что удалённый Claude Code уже подключён.
