# План: Claude Code Workspace

## Цель и границы

Создать интерактивный адаптивный веб-прототип панели для работы с Claude Code, вдохновлённый показанным Cloud-CLI: проекты, сессии, чат, терминал, файлы и Git в одном рабочем пространстве. Эта итерация демонстрирует будущий процесс, но не запускает CLI и не подключается к пользовательскому VPS. Официальная авторизация, выполнение команд только после явного действия пользователя и отсутствие обходных прокси/передачи учётных данных посредникам — обязательные принципы будущей интеграции.

## Реализация и структура

- Vite + React + TypeScript, клиентский SPA без внешних API и ключей.
- Интерфейс работает на `GET /` и использует локальные демонстрационные данные. Все действия прототипа (создание/переключение сессии, переключение вкладок, команды терминала, staging/diff, отправка сообщения, выбор контекста и настройки) интерактивны, но чётко остаются симуляцией.
- Центральная область — рабочая сессия и вкладки `Chat`, `Terminal`, `Files`, `Source Control`; левый rail/сайдбар — проекты и сессии; правая contextual-панель — файлы контекста, инструкции и индикатор бюджета; настройки безопасности доступны из профиля.
- Desktop: компактная IDE-компоновка, панели с ограничениями и возможностью сворачивания; mobile: компактная навигация и переключение рабочих панелей вместо сжатия многоколоночной IDE.
- `src/App.tsx` координирует состояние и экраны; `src/components/` содержит панели проекта, чата, терминала, проводника, Git и контекста; `src/data/` — демонстрационные fixture-данные; `src/styles.css` задаёт токены, адаптивные стили и состояния; `public/manus-routes.json` декларирует маршрут `/`; `app.config.ts` хранит project-logo URL.
- Серверная база данных не используется в прототипе, хотя инфраструктурные возможности проекта уже доступны. Реальный удалённый агент, аутентификация, безопасность shell-команд, постоянное хранение, лимиты и multi-user доступ — отдельная следующая фаза, не маскируемая демонстрацией.

## Дизайн-система

- **Design Movement:** северная полярная консоль — холодная инженерная эстетика редактора кода, без киберпанк-декора.
- **Core Principles:** (1) мгновенно читаемая структура проекта и активной сессии; (2) плотная компоновка IDE с ясной иерархией; (3) статус каждой операции заметен, но не кричит; (4) интерфейс подчёркивает контроль пользователя над контекстом и безопасностью.
- **Color Philosophy:** глубокий сине-графитовый фон `#071827` создаёт спокойную глубину; холодные сине-голубые обводки делят рабочие слои; основной текст светлый и хорошо контрастирует; коралловый `#FF8066` — собственный фирменный сигнал для активного действия, а не для больших заливок; зелёный и янтарный зарезервированы для статусов.
- **Layout Paradigm:** асимметричное многопанельное рабочее место: узкий навигационный rail, project/session sidebar, широкая основная область и контекстная панель. На телефоне панели переходят в последовательные вкладки.
- **Signature Elements:** (1) скобки-маркер проекта с коралловой «полярной искрой»; (2) тонкая линия-орбита вокруг живого статуса агента; (3) ледяные контурные разделители с компактными моноширинными метками состояния.
- **Interaction Philosophy:** любое действие имеет ясную область эффекта; команды и Git-действия подтверждаются понятным локальным UI-состоянием; панели можно свернуть; в прототипе симуляция явно маркируется и не выдаёт себя за реальное выполнение.
- **Animation:** короткие 120–180 мс переходы для табов, сайдбаров и статусов; мягкое появление новых сообщений; без постоянного пульсирования и движущихся фоновых эффектов; отключать плавность при `prefers-reduced-motion`.
- **Typography System:** Golos Text для заголовков и интерфейса; компактная системная моноширина для путей, команд, diff и меток; заголовки 22/16 px, рабочий текст 13–14 px, метаданные 11–12 px.
- **Brand Essence:** Claude Code workbench для разработчиков, который собирает кодового агента, проект и контроль изменений в одном личном рабочем пространстве; характер: спокойный, точный, самостоятельный.
- **Brand Voice:** короткие, ясные подписи без маркетинговой гиперболы. Примеры: «Код — в работе. Контекст — под контролем.»; «Новая сессия».
- **Wordmark & Logo:** компактный знак из раскрывающихся угловых скобок проекта и небольшой коралловой звезды-коммита; рядом — текстовый wordmark `CLAUDE / WORKSPACE`.
- **Signature Brand Color:** полярный коралл `#FF8066`.

## Состав интерфейса

1. Проекты с поиском, активностью, статусом и созданием/открытием.
2. Сессии проекта с созданием, переименованием, продолжением и состояниями работы.
3. Чат с историей, markdown-представлением, блоками кода, копированием, повторной отправкой и локальной имитацией ответа.
4. Терминал с вкладками, историей, понятными состояниями, безопасным mock-исполнением нескольких демонстрационных команд.
5. Дерево файлов, поиск и чтение содержимого с подсветкой синтаксиса.
6. Source Control с изменёнными файлами, diff, staging checkbox, commit message и демонстрационным commit.
7. Markdown-файл с режимом source/preview и рендером списков, ссылок, таблиц и кода.
8. Контекст проекта: прикреплённые файлы, инструкции, приблизительный индикатор использования окна контекста и управление включением файлов.
9. Адаптивный workspace для desktop/tablet/mobile.
10. Экран настроек/безопасности с явным пояснением про self-hosted модель, официальную авторизацию и отсутствие прокси обхода/пересылки credentials.
