# Вход в Claude Code через официальный CLI

Polar запускает официальный, неизменённый Claude Code CLI. Веб-приложение не использует Anthropic API или SDK и не просит вводить API-ключи, пароли Claude, browser cookies либо OAuth/session tokens.

## Первый вход на своём сервере

1. Войдите в Polar под единственной локальной учётной записью владельца.
2. Откройте нужный проект и его вкладку **Терминал**.
3. Запустите штатный CLI:

   ```bash
   claude
   ```

4. Следуйте подсказкам CLI и выполните авторизацию в официальном интерфейсе Anthropic той учётной записью, которой владеете лично. Если CLI напечатает адрес или код подтверждения, откройте адрес в своём браузере и завершите вход там.
5. Вернитесь в терминал. После успешного входа используйте чат Polar: запрос будет выполняться локальным процессом `claude` на вашем сервере.

Веб-пароль Polar и вход Claude Code — разные учётные данные. Не вставляйте секреты Claude в чат Polar, сообщения, `.env`, командные аргументы или GitHub.

## Где хранится вход

CLI самостоятельно хранит свою конфигурацию и состояние входа в выделенном Docker volume `polar_claude_config` (`/claude-config/.claude` и `/claude-config/home`). Веб-сервер не извлекает credential-файлы и не проксирует OAuth-вход. Этот том входит в резервную копию, поэтому относитесь к архиву как к хранилищу секретов: ограничьте доступ и зашифруйте его перед переносом за пределы VPS.

## Повторная авторизация

Если CLI сообщает, что вход не выполнен или истёк, снова откройте терминал проекта и запустите `claude`, затем выполните предложенный CLI официальный login flow. Polar не имеет отдельной формы для токенов и не выпускает токен от имени пользователя.

История чатов Polar хранится отдельно в локальной базе self-hosted приложения. Она не синхронизируется с историей Claude.ai.

Официальная справка: [Claude Code authentication](https://docs.anthropic.com/en/docs/claude-code/authentication).
