# Авторизация подписки Claude (официальная, без заглушек)

Сервис не хранит и не подменяет доступ: он работает через **официальный Claude Code**.
Заглушек в backend нет — каждый запрос уходит в настоящий Claude.

## Вариант A (подписка Claude Pro/Max) — рекомендуемый
1. Установить официальный Claude Code: `npm i -g @anthropic-ai/claude-code`
2. Один раз авторизоваться подпиской: `claude setup-token`
   — откроется ссылка на claude.ai, после подтверждения CLI выдаст долгоживущий токен
     (начинается с `sk-ant-oat...`).
3. Прописать токен в окружение сервиса (не в git):
   `export CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat...`
4. Запустить backend: `node server/index.mjs`
   Проверка: `curl localhost:8787/api/auth/status` → `{"authorized":true,...}`

## Вариант B (через API-ключ)
`export ANTHROPIC_API_KEY=sk-ant-...` — оплата по токенам, не по подписке.

## Что это даёт
- `POST /api/chat` запускает `claude -p ... --output-format stream-json` в рабочей папке —
  это настоящий Claude Code, с реальным выполнением инструментов и правкой файлов.
- `/api/files`, `/api/file`, `/api/terminal` работают с настоящей файловой системой и shell.

## Безопасность
- Сервис по умолчанию слушает `127.0.0.1` — наружу не смотрит. Для удалённого доступа
  используйте SSH-туннель, а не публикацию порта.
- Токен подписки хранится только в окружении процесса; в репозиторий не попадает.
