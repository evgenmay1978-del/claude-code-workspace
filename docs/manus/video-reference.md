## Что именно показано

Self-hosted web-панель на личном VPS, доступная из браузера с компьютера, планшета и телефона. Основной интерфейс — IDE-подобное рабочее место с проектами и сессиями в sidebar и четырьмя режимами: Chat, Shell, Files и Source Control. Чат поддерживает Markdown и отображение хода обработки; модель может работать с файлами проекта; в ролике также показано переключение Claude/Codex и авторизация по ссылке.

## Что берём и улучшаем для Polar Workspace

Сохраняем основную модель «один сервер владельца → браузерное рабочее место → проекты/чаты/файлы/Shell/Git». Используем официальный неизменённый Claude Code CLI без Anthropic API key и без SDK-пакета; владелец сам входит через CLI на своём сервере. Веб-версия должна адаптироваться к малому экрану как телефонный клиент: полноценный chat-first экран, нижняя навигация и выдвижные панели вместо уменьшенной desktop IDE. Добавляются архивируемая история, реальная работа с файлами и Git, потоковый ответ/статусы инструментов, проектные инструкции и экспортируемые локальные backup-архивы.

## Границы и безопасность

В ролике звучат утверждения «без VPN» и «нулевой риск блокировки», но это не проверяемые гарантии. Polar не будет проксировать трафик, обходить региональные ограничения, обещать защиту от блокировки или давать общий доступ к личной подписке третьим лицам. Авторизация остаётся у одного владельца и проходит в официальном CLI; внутренние reasoning-содержания не раскрываются — интерфейс показывает только безопасный статус/инструментальные события. Веб-клиент хранит собственные чаты на сервере и не выдаёт их за синхронизированную историю Claude.ai.

В видеореференсе названы Claude и ChatGPT/Codex. За рамками текущего запроса оставлен OpenAI/Codex: владелец отдельно уточнил, что использует только Claude Code по подписке и не хочет подключать API или SDK.
